# 🚀 Quick Start Guide

## ✅ Installation Complete!

All dependencies have been installed successfully. The development server should be starting now.

## 🌐 Access the Email Inbox Prototype

The development server is running. Open your browser and navigate to:

**Email Inbox**: http://localhost:5173/inbox

Or click on **"Email Inbox"** in the sidebar navigation.

## 📧 What You'll See

### Email Inbox Features:

1. **Left Panel - Email List**
   - 5 sample emails with different classifications
   - BOL (Bill of Lading) emails
   - Tender submission emails  
   - Lumper receipt emails
   - Classification badges and workflow status indicators

2. **Center Panel - Email Detail**
   - Full email content
   - Attachments list
   - Extracted data fields
   - Email metadata

3. **Right Panel - Classification & Workflow**
   - Document classification with confidence scores
   - Workflow execution status
   - Action breakdown
   - Case links

## 🎯 Try These Features

1. **Click on different emails** to see their details
2. **Use the search bar** to filter emails
3. **Click the classification tabs** (BOL, Tender, Lumper) to filter
4. **View extracted data** for each document type
5. **Check workflow status** in the right panel
6. **Click case links** to see case associations

## 📊 Sample Data Included

- **Email 1**: BOL from FastTrack Logistics (Completed workflow, Case created)
- **Email 2**: Tender submission for IT Services (Completed workflow, Case created)
- **Email 3**: Lumper Receipt from Dock 7 (Completed workflow, Case created)
- **Email 4**: Urgent BOL from Express Logistics (In-progress workflow)
- **Email 5**: Tender for Facilities Management (Completed workflow, Case created)

## 🛠️ Development Commands

- **Stop server**: Press `Ctrl+C` in the terminal
- **Restart server**: Run `npm run dev` again
- **Build for production**: `npm run build`
- **Preview production build**: `npm run preview`
